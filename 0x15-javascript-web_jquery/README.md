## Description

This project focuses on using JavaScript and the jQuery library for various front-end web development tasks. It includes exercises ranging from basic DOM manipulation to handling API requests.

## Learning Objectives

By the end of this project, you should be able to:

- **General:**
  - Explain why JQuery simplifies front-end programming (don’t forget to tweet with #ilovejquery!)
  - Select HTML elements using JavaScript and JQuery
  - Differentiate between ID, class, and tag name selectors
  - Modify HTML element styles and content
  - Modify the DOM
  - Perform GET and POST requests using JQuery Ajax
  - Bind and listen to DOM and user events

## Requirements

- **Editors:** vi, vim, emacs
- **Browser:** Chrome (version 57.0 or later)
- **New Line:** All files should end with a new line
- **README.md:** Must be present in the root of the project folder
- **Code Style:** Semistandard compliance with the flag `--global $` (e.g., `semistandard *.js --global $`)
- **JQuery Version:** 3.x
- **Restrictions:** 
  - Use of `var` is not allowed
  - HTML should not reload for each action; manage DOM manipulation, value updates, and data fetching without reloads
